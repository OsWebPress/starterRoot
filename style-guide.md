# Site Style Guide

> Generated by the style-website skill. Use this document as a prompt when restyling makedown token components (`root/component/makedown/`) or content components (`root/component/`). Every value is concrete — no placeholders. An AI reading this should be able to produce consistent Tailwind classes without asking further questions.

---

## Design Mood

Light, warm, and beach-inspired. The page feels like a calm coastal day — a soft blue sky background, warm sandy tones for contained sections and the navigation bar, and rich brown text that is easy to read without being harsh. The design is minimal and clean but not sterile: there is warmth in the colours and character in the typography. Headings use a geometric sans-serif with subtle Bauhaus proportions; body text is highly readable. The overall impression is personal and grounded, not corporate.

## Typography

**Font setup:** Both fonts are loaded from Google Fonts. Add the following to the frontend `<head>` if not already present:
```
https://fonts.googleapis.com/css2?family=Josefin+Sans:wght@400;600;700&family=Inter:wght@400;500;600&family=JetBrains+Mono:wght@400;500&display=swap
```

| Role | Font family | Tailwind size | Weight | Letter spacing |
|---|---|---|---|---|
| h1 | Josefin Sans | `text-4xl` | `font-bold` | `tracking-tight` |
| h2 | Josefin Sans | `text-3xl` | `font-semibold` | `tracking-tight` |
| h3 | Josefin Sans | `text-2xl` | `font-semibold` | `tracking-normal` |
| h4 | Josefin Sans | `text-xl` | `font-medium` | `tracking-normal` |
| h5–h6 | Josefin Sans | `text-lg` / `text-base` | `font-medium` | `tracking-normal` |
| Body text | Inter | `text-base` | `font-normal` | `tracking-normal` |
| Inline code / highlight | JetBrains Mono | `text-sm` | `font-normal` | `tracking-normal` |
| Code block | JetBrains Mono | `text-sm` | `font-normal` | `tracking-normal` |

Line height (body): `leading-relaxed` (1.625)
Paragraph max-width: `max-w-prose` (~65ch) — keeps long text readable

## Spacing

Base unit: 4px (Tailwind default — do not customise)
Paragraph gap: `mb-4`
Section gap (between major page sections): `py-12`
Page horizontal padding: `px-6` (mobile) / `px-8` (desktop, `md:px-8`)
Page content max-width: `max-w-3xl mx-auto`

## Navigation Bar

Background: `bg-amber-100` with `border-b border-amber-300`
Height: `h-14`
Link style: Plain text, `text-stone-700`, `font-medium`, hover gets `text-amber-600` and an `underline` with `underline-offset-4`
Active / current-page indicator: `text-amber-600` with `border-b-2 border-amber-500`
Sticky: No — scrolls away with the page
Mobile: Hamburger icon (three lines, `text-stone-700`) opens a vertical drawer below the bar with the same background. Links stack vertically with `py-3 px-6` padding. Drawer closes on link click or outside tap.
Logo/wordmark: Text "oswin" (or logo image when available), left-aligned, `font-bold text-stone-800` in Josefin Sans

## Makedown Token Styling

### Headings

All headings use Josefin Sans (`font-['Josefin_Sans']`), `text-stone-800`, with `mt` top margin to create visual separation and `mb` bottom margin before the following content.

- **h1** — `text-4xl font-bold tracking-tight text-stone-800 mt-8 mb-6`
- **h2** — `text-3xl font-semibold tracking-tight text-stone-800 mt-6 mb-4`
- **h3** — `text-2xl font-semibold text-stone-800 mt-5 mb-3`
- **h4** — `text-xl font-medium text-stone-700 mt-4 mb-2`
- **h5** — `text-lg font-medium text-stone-600 mt-3 mb-2`
- **h6** — `text-base font-medium text-stone-500 mt-3 mb-1`

### Paragraph / Text

Body text: `text-base text-stone-700 leading-relaxed max-w-prose`
The `richText` wrapper adds no extra background — it inherits whatever the parent section provides.

### Inline Formatting

- **Bold:** `font-semibold text-stone-800` — slightly darker than body to signal emphasis
- *Italic:* `italic text-stone-600` — softened colour, not a different font
- `Highlight / inline code:` `font-['JetBrains_Mono'] text-sm bg-amber-100 text-amber-900 rounded px-1.5 py-0.5`

### Code Block

Multi-line fenced code block: `font-['JetBrains_Mono'] text-sm bg-stone-800 text-amber-100 rounded-lg p-4 overflow-x-auto my-4 leading-relaxed`

### Links

Default: `text-sky-500 underline underline-offset-2`
Hover: `text-sky-700`
Visited: `text-sky-700`

### Blockquote

`border-l-4 border-amber-400 bg-amber-50 pl-4 py-2 my-4 italic text-stone-600 rounded-r`

### Horizontal Rule

`border-t border-amber-200 my-8`

### Lists

Unordered bullet: `list-disc pl-6 mb-1 text-stone-700` — bullet colour inherits `text-amber-500` via a `marker:text-amber-500` class
Ordered number: `list-decimal pl-6 mb-1 text-stone-700 marker:text-amber-700`
Indent per level: `pl-6`

### Checkbox

Unchecked: `w-4 h-4 rounded-sm border-2 border-stone-400`
Checked: `w-4 h-4 rounded-sm bg-amber-500 border-2 border-amber-500` with a white checkmark

## Content Component Archetypes

> When creating or restyling any component, identify its archetype and apply these tokens. A component may combine archetypes.

### Card

Used for: ContentCard, BlogPreview, and any component with a self-contained surface.

Background: `bg-stone-50`
Border: `border border-stone-200`
Border radius: `rounded-xl`
Shadow: `shadow-sm hover:shadow-md transition-shadow`
Inner padding: `p-6`

### Callout

Used for: Info, PopOut, and any component that draws attention or adds context.

Accent position: Left border strip
Accent colour: `border-l-4 border-amber-400`
Background tint: `bg-amber-50`
Shadow: `shadow-sm`
Inner padding: `p-4`

### Layout wrapper

Used for: Section, FullBleed, and any component that sets a background zone for a region of the page.

Primary background (sand): `bg-amber-100`
Alternative background (blue): `bg-sky-100`
Neutral background (white): `bg-white`
Vertical padding: `py-12`
Interaction: Layout wrappers break out of the prose max-width. Content inside them should still use `max-w-3xl mx-auto` unless deliberately full-bleed.

### Media grid

Used for: ImageGrid, MagicGrid.

Gap: `gap-4`
Item border radius: `rounded-lg`
Hover effect: `hover:scale-105 hover:shadow-md transition-all duration-200`

### Content + image

Used for: SideImage.

Proportions: 50/50 (`grid grid-cols-2`) — image and text columns equal
Gap: `gap-8`
Background: Transparent (inherits parent section)

### Listing / feed

Used for: BlogOverview, BlogPreview.

Item style: Inherits Card archetype
Date: `text-sm text-stone-400 font-normal`
Tag / category: `text-xs bg-amber-100 text-amber-800 rounded-full px-2 py-0.5 font-medium`
Item gap: `gap-6` between cards

### Display text

Used for: WordArt.

Treatment: Gradient from `text-amber-500` to `text-sky-500` (left to right) using `bg-gradient-to-r from-amber-500 to-sky-500 bg-clip-text text-transparent`
Alternative solid: `text-stone-800`
Size: `text-5xl` or larger
Weight: `font-bold`

### Data / widget

Used for: CountDown.

Container style: Inherits Card archetype
Primary value (digit): `text-sky-600 font-bold text-3xl`
Label: `text-stone-400 text-sm uppercase tracking-wide`

## Tailwind Constraints & Notes

- **UnoCSS runtime** is used for Tailwind in this project. Avoid arbitrary value syntax (`w-[123px]`, `text-[#aabbcc]`). Use only named Tailwind palette classes and standard scale steps.
- **Google Fonts** (Josefin Sans, Inter, JetBrains Mono) must be loaded at the SPA level in the frontend `index.html` — remote components cannot inject `<link>` tags into `<head>`.
- **FullBleed** handles full-viewport-width layouts. Do not add negative margins in individual components to achieve full-bleed — use the FullBleed component instead.
- **makedown/ components** all receive a `body` prop and use `<LoadComponent _component="makedown/richText" :body="body" />` for inline text. Only change the wrapping element's classes — do not alter this pattern.
- **Page background** (`sky-100`) is set at the body or app root level, not inside individual components. Components should use transparent backgrounds unless they intentionally introduce a new background zone (Layout wrapper archetype).
- **Heading font** must be applied with the class `font-['Josefin_Sans']` in Tailwind utility syntax since it is not in the default Tailwind font stack.
- **Inter** is close enough to the system sans-serif stack that it can be applied with `font-sans` if the font fails to load — add it as the first entry in the sans stack if customising the Tailwind config.
